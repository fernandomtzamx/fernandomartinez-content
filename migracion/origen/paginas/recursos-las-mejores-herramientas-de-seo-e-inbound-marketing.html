Comparto contigo una recopilación de las mejores herramientas y recursos para hacer SEO e Inbound Marketing.

  • Análisis y métricas
    Webtrends
    Paquete de nivel empresarial de análisis web.
    Uprise.io
    Encuentra y analiza el mejor contenido y autores de tu nicho vertical.
    Tagboard
    Utiliza hashtagas para buscar y recolectar información pública de los medios sociales segundos después de ser publicados a redes como Twitter y Facebook.
    StatCounter
    Ofrece análisis web gratuito siempre que tengas menos de 250,000 páginas vistas al mes.
    Social Crawlytics
    Identifica el contenido más compartido de tus competidores y encuentra quienes compartieron ese contenido.
    ShareTally
    Es una herramienta gratuita que te da información sobre contenido compartidos en medios sociales en diferentes redes sociales.
    Shared Count
    Rastrea urls compartidas, likes, tweets, etc.
    Segment.io
    Ofrece una forma sencilla para que los desarrolladores integren las API de mútilples provedores de análisis web dentro de sus aplicaciones.
    Piwik
    Piwik es un software de código abierto para análisis de sitios web que otorga datos de gran valor sobre los visitantes de tu sitio web.
    PicStats
    Información para analizar de cualquier cuenta de Instagram.
    KISSmetrics
    Haz que tus productos, ventas, marketing y soporte trabajen juntos para mejorar las métricas que importan.
    Intercom Observe
    Ve quienes son tus clientes y lo que hacen con tu producto, en tiempo real.
    Hotjar
    Mapas de calor, grabación de visitantes, embudos de conversión, análisis de formularios, encuestas de satisfacción en una plataforma.
    Heap Analytics
    Heap es un software de análisis web y móvil que captura automáticamente todo. Puedes analizar instatáneamente y de forma retroactiva.
    Google Analytics Configuration Tool
    Instala de manera sencilla el código universal de Google Analytics.
    Google Analytics
    Google Analytics te da estadísticas detalladas sobre el tráfico de tu sitio web y las fuentes de referencia.
    Crazy Egg
    Mapas de calor y reportes de mapas de scroll, para que puedas entender como tus visitantes interactúan con tu página web.
    Clicky
    Es una manera sencilla de monitorear, analizar y reaccionar al tráfico de tu sitio web en tiempo real.
    BuzzSumo
    Analiza que contenido funciona mejor para un tema o competidor.

    How to Start a Startup
    Todo lo que sabemos sobre iniciar una startup, de algunos de los expertos mundiales.

    Una guía oficial de Google para la optimización en motores de búsqueda.
    Google Quality Rating Guideline v5.0
    Este documento secreto, es utilizado por los empleados de Google para revisar de forma manual la calidad de un sitio web.

    Una guía detallada para iniciar en el SEO escrita por Moz.
    Beginner's Guide to Link Building
    Una guía práctica para hacer contrucción de links (link building).
    Advance Guide To SEO
    Una guía detallada de Quicksprout con temas básicos y avanzados de posicionamiento web.

  • Herramientas
    Shopify

    Shopify es una plataforma de comercio electrónico que ofrece una prueba gratuita para ayudar a los emprendedores a iniciar su propia tienda en línea sin la ayuda de una agencia. Esta prueba gratuita te permite experimentar con el diseño de tu tienda, agregar productos, configurar tu proceso de pago y mucho más. Con la prueba gratuita de Shopify, puedes obtener una idea de cómo funciona la plataforma y descubrir si es adecuada para tu negocio. Además, te permite experimentar con el diseño y la configuración de tu tienda sin tener que invertir una gran cantidad de dinero.
